# Rebar

A React-based IFC (BIM) model viewer built with `web-ifc-viewer` and Three.js. Browse sample IFC files, render them in 3D, and inspect element properties.

## Getting Started

```bash
npm install
npm start
```

Runs the app at [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm start` – start the dev server (regenerates the IFC file manifest first)
- `npm run build` – production build
- `npm test` – run tests
